# Golden Set 策略

本目录本轮只定义 Golden Set 策略，当前不开始打标、不生成样本数据。

## 建议规模与范围

```text
综合知识：
100–150 道高价值样本

案例：
优先覆盖全部案例候选集

论文：
先做题目 taxonomy
不复制大量范文
```

## 用途

Golden Set 未来用于验证：

- taxonomy 粒度
- aliases
- topic mapping
- capability mapping
- confidence

样本应覆盖代表性的知识域、题型、来源和边界情况，并保留可追溯的 source provenance。Golden Set 是验证数据契约和归一化规则的基准，不是完整题库的替代品。

## 当前禁止事项

- 不批量映射 1822 道题
- 不在本轮开始综合题、案例题或论文题的全量打标
- 不复制第三方题面、解析、范文或 PDF
- 不把尚未验证的映射当作 Taxonomy v0.1
