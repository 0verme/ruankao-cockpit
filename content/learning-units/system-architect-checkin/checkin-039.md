# 推荐系统：算法、流程与多样性

## 今天学会什么
- 解释推荐系统如何回应信息过载
- 比较协同过滤、基于内容与混合推荐
- 梳理建立流程及冷启动、同质化的来源对策

## 先建立直觉

推荐系统根据用户行为过滤信息，试图从大量商品、内容或服务中挑出可能相关的候选。推荐质量不只看算法，还依赖数据收集、清洗、评估和上线后的持续调整。

## 核心知识

### 算法类型

协同过滤依据相似用户的偏好；基于内容的方法分析用户喜欢内容的特征并推荐相似内容；混合推荐组合多种算法以规避单一算法局限。

### 建设过程

来源列出的链路为行为数据收集、数据清洗与格式统一、模型构建、以准确率/召回率等评估、部署并持续优化。

### 常见问题

冷启动可用热门兜底、通过注册引导收集偏好、基于内容推荐、利用人口统计属性或给新内容曝光并按早期反馈调整。推荐同质化可通过多样性重排、给陌生内容留出份额、评估惊喜度、调整冷热内容权重以及提供用户控制来缓解。

## 一张脑图式结构

```text
行为数据 → 清洗 → 模型
├─ 协同过滤：相似用户偏好
├─ 内容推荐：相似内容特征
└─ 混合：组合方法
评估 → 上线 → 持续优化；关注冷启动与同质化
```

## 易混点 / 对比

协同过滤从用户之间的偏好相似性出发；基于内容从项目特征出发；混合方法组合两者。冷启动与推荐同质化是不同问题，来源给出的缓解措施也不同。

## 架构师视角

推荐系统架构要把行为数据管道、模型、在线服务和评估更新连起来。优化准确率/召回率之外，来源还提醒多样性和新内容曝光；需要在用户相关性与内容探索之间做明确取舍。
